## Before you start

- You need Windows 10 or Windows 11.
- Download the Windows installer from the web app. See [Download Sayso](/help/desktop-app/download-sayso/).

<Screenshot src="/help/desktop-app/download-sayso-1.webp" alt="The Download Sayso window with Sayso for Windows" />

## Install

1. Open your Downloads folder and double-click the Sayso installer. If Microsoft Edge says the file isn't commonly downloaded, see [Microsoft Edge won't keep the download](/help/desktop-app/antivirus-blocking/#microsoft-edge-wont-keep-the-download).
2. If Windows shows <Ui>Windows protected your PC</Ui>, click <Ui>More info</Ui>, then <Ui>Run anyway</Ui>.
3. Follow the installer's steps. Keep the suggested install folder or choose another one.
4. Sayso adds a shortcut to your desktop and Start menu.

Sayso installs for your Windows user only. You don't need an administrator account.

<Callout type="note" title="Install fails or never finishes?">
Your antivirus is blocking it. PC Matic and McAfee have blocked Sayso. Add Sayso to your antivirus allow list, or pause it for the install and turn it back on after. See [Antivirus or SmartScreen blocked Sayso](/help/desktop-app/antivirus-blocking/).
</Callout>

## Open Sayso for the first time

1. Open Sayso from the desktop shortcut or the Start menu.
2. Sign in with your Sayso email and password. See [Sign in to the desktop app](/help/desktop-app/sign-in-desktop/).
3. If Windows microphone access is turned off, Sayso shows a <Ui>Permissions</Ui> screen. See [Allow microphone access on Windows](/help/desktop-app/windows-microphone-permission/).

Sayso lives in the notification area of your taskbar, next to the clock. Windows hides new icons behind the <Ui>^</Ui> arrow. To keep Sayso in view, see [Keep Sayso visible on the Windows taskbar](/help/desktop-app/pin-sayso-windows-taskbar/).

<Callout type="tip">
On Windows, Sayso hears the lead through your computer's audio output. It doesn't need the second permission a Mac needs.
</Callout>
