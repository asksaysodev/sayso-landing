## Before you start

- You need Windows 10 or Windows 11.
- Download the Windows installer from the web app. See [Download Sayso](/help/desktop-app/download-sayso/).

## Install

1. Open your Downloads folder and double-click the Sayso installer.
2. If Windows shows <Ui>Windows protected your PC</Ui>, click <Ui>More info</Ui>, then <Ui>Run anyway</Ui>.
3. Follow the installer's steps. You can keep the suggested install folder or choose another one.
4. When it finishes, Sayso adds a shortcut to your desktop and to your Start menu.

Sayso installs for your Windows user only, so you don't need an administrator account.

<Callout type="note" title="Install fails or never finishes?">
Your antivirus is the most likely cause. PC Matic and McAfee have both blocked Sayso. Add Sayso to your antivirus allow list, or pause it for the install and turn it back on after. See [Antivirus or SmartScreen blocked Sayso](/help/desktop-app/antivirus-blocking/).
</Callout>

## Open Sayso for the first time

1. Open Sayso from the desktop shortcut or the Start menu.
2. Sign in with your Sayso email and password. See [Sign in to the desktop app](/help/desktop-app/sign-in-desktop/).
3. If Windows microphone access is turned off, Sayso shows a <Ui>Permissions</Ui> screen. See [Allow microphone access on Windows](/help/desktop-app/windows-microphone-permission/).

Sayso then lives in the notification area of your taskbar, next to the clock. Windows often hides new icons behind the <Ui>^</Ui> arrow, so the next step is to make it easy to find: [Keep Sayso visible on the Windows taskbar](/help/desktop-app/pin-sayso-windows-taskbar/).

<Callout type="tip">
On Windows, Sayso hears the lead through your computer's audio output, so it does not need a second permission like it does on a Mac.
</Callout>
