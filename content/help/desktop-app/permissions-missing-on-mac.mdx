macOS ties permissions to one exact copy of an app. If something doesn't match, the switches look on in System Settings but Sayso can't use them, and it keeps showing the Permissions screen.

## Fix 1: Remove extra copies

The most common cause is two copies of Sayso, for example "Sayso" and "Sayso 2", usually from choosing <Ui>Keep Both</Ui> during an install.

1. Quit Sayso from the Sayso menu.
2. Open your Applications folder and drag every copy of Sayso to the Trash.
3. Empty the Trash.
4. Install Sayso again. When asked, choose <Ui>Replace</Ui>, never <Ui>Keep Both</Ui>. See [Install Sayso on a Mac](/help/desktop-app/install-on-mac/).
5. Open Sayso and allow both permissions again.

## Fix 2: Clear the old permissions

If you had Sayso installed before June 2026, the old version's permissions can get stuck. Clear them once so macOS asks fresh:

1. Open <Ui>System Settings</Ui> > <Ui>Privacy & Security</Ui> > <Ui>Screen & System Audio Recording</Ui> (or <Ui>Screen Recording</Ui>).
2. Select Sayso and click the minus (<Ui>-</Ui>) button to remove it, or turn it off. Click <Ui>Quit</Ui> if asked.
3. Do the same under <Ui>Microphone</Ui>.
4. Open Sayso again. It asks for both permissions; allow them and click <Ui>Quit and Reopen →</Ui>.

<Callout type="note" title="Comfortable with Terminal?">
You can clear both at once. Quit Sayso, open Terminal and run these two lines, then open Sayso and allow both permissions:

```
tccutil reset ScreenCapture com.asksayso.app
tccutil reset Microphone com.asksayso.app
```
</Callout>

This is a one-time fix. If Sayso still asks after both fixes, restart your Mac once, then email support@asksayso.com with [your logs](/help/support/send-your-logs/).
