Every agent starts with Sayso's built-in Playbooks. Scripts that someone uploads are only in their own account. There isn't a way yet for an Owner or Admin to publish a script to the whole team.

## Give your team the same script

1. Save your script as a PDF, DOCX or TXT file (up to 20 MB).
2. Send it to your agents in your team chat or by email.
3. Each agent uploads it in the desktop app. See [Upload, rename and remove your own playbooks](/help/desktop-app/upload-playbooks/).
4. Ask them to mark it as a favorite so it is easy to find.

Agents still choose which script to open on a call.

<Callout type="tip">
Give the file a clear name, like "Expired listing script v2". When you update it, send the new version and ask agents to remove the old one, so nobody reads from an outdated script.
</Callout>
