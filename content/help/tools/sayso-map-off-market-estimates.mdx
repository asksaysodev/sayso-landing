When the home you searched is off market, Sayso Map may show an automated value estimate labeled <Ui>AVM</Ui> near the address. Select the information icon next to the confidence label for details. Use the estimate as a starting point and review the comparable homes before discussing value or list price.

<Screenshot src="/help/tools/sayso-map-estimate.webp" alt="The AVM amount, High confidence label and open information note for an off-market home" />

## What the confidence label means

- **High** generally means the underlying estimate has a narrower range of possible values.
- **Medium** generally means the underlying range is wider.
- **Low** can reflect a wide range, limited comparable data or a reason to be cautious about using nearby homes to estimate value.

Confidence can drop after the [condition badges](/help/tools/sayso-map-condition-ratings/) load. For example, if the home last sold many years ago and most comparable homes are new or fully updated, Map may show <Ui>Nearby homes look more updated. Estimate may be high.</Ui> The confidence label changes while the estimated dollar amount stays the same.

## How Map uses the estimate

When an estimate is available, Map uses it to help match nearby homes by price. If there is no estimate, Map can still show similar homes and skips the price comparison against the home you searched. For a home listed for sale, Map uses its list price for matching.

See [Change Sayso Map filters](/help/tools/sayso-map-filters/).
