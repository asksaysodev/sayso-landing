If you can't remember your password, reset it from the web app sign-in page. The same password works in the web app and the desktop app.

## Request a reset link

1. Go to [app.asksayso.com/login](https://app.asksayso.com/login) and click <Ui>Forgot password?</Ui>.
2. On the <Ui>Reset password</Ui> page, enter the email you use for Sayso.
3. Click <Ui>Send reset link</Ui>.

<Screenshot src="/help/web-app/reset-password-1.webp" alt="The Reset password page in the Sayso web app with the email field" caption="The Reset password page." />

A note confirms that if an account exists for that email, a recovery link was sent. Check your inbox and your spam folder.

Didn't get it? Wait for the countdown to finish, then click <Ui>Resend reset link</Ui>.

<Callout type="tip">
On the desktop app sign-in screen, <Ui>Forgot password?</Ui> opens this same page in your browser.
</Callout>

## Create a new password

1. Open the email and click the reset link.
2. On <Ui>Create new password</Ui>, enter your new <Ui>Password</Ui> and type it again in <Ui>Repeat password</Ui>. It needs at least 8 characters and at least one number.
3. Click <Ui>Reset password</Ui>.

Then sign in with your new password on the web app and on the desktop app.

## The link says it expired

Reset links only work for a limited time. If you see that the link has expired or is no longer valid, click <Ui>Request new link</Ui> and start again.
